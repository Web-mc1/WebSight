🛡️ Staff Command Cheat Sheet

Quick command reference for CheeseWhiz SMP Moderators & Admins

⚖️ Moderation & Punishments
/ban <player> <reason> Permanently ban a player from the server.
/tempban <player> <time> <reason> Temp ban (e.g., 1d = 1 day, 2h = 2 hours).
/mute <player> <reason> Silence a player in global chat.
/warn <player> <reason> Issue an official warning record.
/history <player> View previous warnings, mutes, and bans.
🔑 Permissions (LuckPerms)
/lp user <player> info Check user rank and assigned permissions.
/lp user <player> parent set <rank> Set a user's primary group/rank.
/lp editor Generate web editor URL for quick permissions management.
🗺️ WorldEdit & Protection
//wand Get the selection wand (Wooden Axe).
//set <block> Fill current selection with specified block.
/rg define <name> Protect selection as a WorldGuard region.
/rg flag <name> <flag> <allow/deny> Configure region rules (e.g., pvp deny).
⚡ Performance & Optimization
/tps View current server Ticks Per Second (Target: 20.0).
/lagscope Open performance diagnostic tool.
/lagg clear Clear dropped ground items manually.
/chunky start Pre-generate world chunks.
🔍 Anti-Xray & Player Tracking
/minertrack check <player> Check ore mining ratios for suspicious X-Ray behavior.
/minertrack alerts Toggle live staff notifications for fast ore mining.
/tp <player> Teleport directly to a player to observe them.
👾 NPCs & Holograms
/fancynpcs create <name> Spawn an interactive NPC at your location.
/hologram create <name> <text> Create floating 3D text in the world.
